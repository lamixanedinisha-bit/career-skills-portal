# Deployment plan (summary)

Phased transition, as set out in the ICT306 report:

1. Requirements and stakeholder sign-off
2. Design and Moodle integration
3. Pilot with a limited cohort
4. Full deployment, with training and support

Includes a cost-benefit analysis, risk register and phased roadmap in the original report. No deployment scripts are included here — this repo is documentation only.
